¿Cómo funciona?

Gemini lee las fotos y crea preguntas usando tu material. En cada práctica tienes tiempo para responder, recibes una evaluación orientativa, una respuesta modelo y recomendaciones para mejorar. No sustituye el cuadernillo ni las indicaciones oficiales de la olimpiada.

La versión requiere conexión a internet y que el servidor esté iniciado. La API gratuita puede tener límites de uso y las condiciones de privacidad dependen del proveedor.
